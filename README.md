# TINOLI — There Is No Other Like It

> Галерея авторских украшений, вышитых вручную бисером и кристаллами.
> Ночная витрина мастерской: каждая вещь сначала вышивается бисером на глазах, потом показывается в свете.

**Сайт:** [tinoli.ru](https://tinoli.ru)
**Репозиторий:** [github.com/SergioTheFirst/TINOLI](https://github.com/SergioTheFirst/TINOLI)
**Хостинг:** GitHub Pages, свой домен через `CNAME`
**Прежняя версия:** [tinoli.ru/classic/](https://tinoli.ru/classic/), ссылка в подвале каждой страницы

## Быстрый старт

```bash
python server.py        # или двойной щелчок по server.bat
```

- Сайт: `http://localhost:8000`
- Админ-панель: `http://localhost:8000/admin.html`

Нужен Python 3.8 или новее, только стандартная библиотека. Работает и на слабом 32-битном Windows.

## Как устроен сайт

Статический сайт без сборки: HTML, один файл стилей, один скрипт. Тексты и работы приходят из JSON,
поэтому всё содержимое редактируется в админке.

```
TINOLI/
├── index.html            Главная: витрина с вышивкой, «Работы», «Мастер», «Написать мастеру»
├── about.html            Мастер (текстовая страница)
├── contact.html          Написать мастеру: каналы связи из config.json
├── privacy.html          Политика обработки персональных данных (юридический текст)
├── 404.html              Страница «Такой страницы нет»
├── gallery.html          Старый адрес галереи: переадресация на /#works с сохранением фильтра
├── works/
│   ├── works.json        Каталог работ
│   ├── images/           Фотографии работ
│   └── <id>/index.html   Страницы работ, их создаёт server.py (руками не править)
├── sitemap.xml           Создаётся server.py вместе со страницами работ
├── config.json           Все тексты, контакты, SEO, токен Cloudflare Web Analytics
├── css/site.css          Весь дизайн нового сайта
├── js/site.js            Весь скрипт нового сайта
├── js/admin-edit.js      Окно редактирования работы в админке
├── fonts/                Jost и Noto Serif Display Condensed (латиница и кириллица)
├── img/logo.svg          Логотип
├── favicon.svg, favicon.ico, apple-touch-icon.png, icon-512.png, og.png
├── classic/              Прежняя версия сайта (заморожена, закрыта от поисковиков)
├── robots.txt, CNAME
└── docs/redesign/        Концепция и решения по редизайну (DIRECTION.md)

Только на компьютере с админкой (в .gitignore): server.py, admin.html, *.bat, secrets.json, tests/
```

Главная читает `config.json` и `works/works.json`.

- **Каталог пуст.** В витрине вышивается знак TINOLI: кристалл в бисерной обшивке и кольцо из
  трёх рядов бисера. Раздел «Работы» скрыт, а рядом с витриной стоит фраза «Первые работы
  появятся в этой витрине» (текст `home.empty_text` в настройках).
- **Работы есть.** Новейшая работа раскладывается в витрине на бисер и проявляется фотографией.
  Ниже — сетка работ с фильтром по видам: 12 карточек сразу, остальные при прокрутке.
  Фильтр сохраняется в адресе (`?category=brooch`).
- **Второй кадр («Как носится»).** Появляется при наведении мыши, по фокусу с клавиатуры или по
  кнопке на карточке (для телефонов).

Страница работы `/works/<id>/` — статическая. Ссылка на неё в Telegram показывает превью с фото.
На странице есть:
- кадры «Украшение», «Как носится», «Деталь»;
- лупа при наведении курсора;
- паспорт работы: вид, материалы, размер, год;
- описание и соседние работы.

## Каталог работ

Каждая работа — объект в `works/works.json`:

```json
{
  "id": "20261012_101500",
  "filename": "20261012_101500.jpg",
  "filename_hover": "20261012_101500_hover.jpg",
  "filename_detail": "20261012_101500_detail.jpg",
  "title": "Название",
  "description": "Описание. Пустая строка начинает новый абзац.",
  "category": "brooch",
  "date": "2026-10-12",
  "materials": "Хрустальные стразы, японский бисер Miyuki, рубка",
  "size": "7,4 × 3,1 см",
  "year": "2026"
}
```

| Поле | Что это |
|------|---------|
| `id` | Время добавления `ГГГГММДД_ЧЧММСС`, уникальный номер |
| `filename` | Кадр «Украшение» (обязательный) |
| `filename_hover` | Кадр «Как носится», украшение на человеке (необязательный) |
| `filename_detail` | Кадр «Деталь», макросъёмка вышивки для лупы (необязательный) |
| `title`, `description` | Название и описание |
| `category` | `brooch`, `earrings`, `necklace`, `bracelet`, `ring`, `other` |
| `date` | Дата добавления, по ней идёт порядок (новые первыми) |
| `materials`, `size`, `year` | Паспорт работы, выводится только заполненное |

Тексты на сайте не должны содержать ничего коммерческого.

## Админ-панель

1. Запустите `server.bat` и откройте `http://localhost:8000/admin.html`.
2. **Добавить работу.** Три фото (основное обязательно), название, вид, описание, материалы,
   размер, год. Фото сжимаются в браузере: основное и «как носится» до 1500 px, «деталь» до 2200 px.
3. **Управление работами.** Правка текстов и паспорта; замена любого из трёх фото; удаление
   второго и третьего кадра; удаление работы целиком.
4. **Настройки сайта.** Все тексты из `config.json`, включая раздел «Главная страница».
5. **Публикация.** Отправка на GitHub, см. ниже.

После каждого изменения сервер пересоздаёт страницы работ и `sitemap.xml`.

## Публикация

Публикация идёт через GitHub API, без git. Токен хранится только в `secrets.json`, его вставляют
один раз на вкладке «Публикация». Нужен fine-grained токен: только репозиторий
`SergioTheFirst/TINOLI`, право Contents: Read and write. Classic-токен с правом `repo` тоже
работает, но открывает все репозитории владельца.

Что отправляется:
- **По умолчанию** — только содержимое: `config.json`, `sitemap.xml` и папка `works/`.
  Устаревшие файлы сайта на компьютере с админкой не перезапишут дизайн.
- **С галочкой «Также опубликовать код сайта»** — все файлы, кроме перечисленных в `.gitignore`.
  Нужна только после обновления дизайна.

Как это работает:
- Неизменённые файлы не отправляются повторно.
- Фото и страницы удалённых работ удаляются с GitHub (только внутри `works/`).
- Если публикация удалит с GitHub больше 5 файлов или заменит каталог на сайте пустым, админка
  сначала спросит подтверждение и покажет, что будет удалено.
- Файл с токеном внутри никогда не уйдёт: публикация остановится и назовёт файл.
- `server.py`, `admin.html`, `*.bat`, `tests/`, `tools/`, скрытые папки и копии `secrets` не
  публикуются ни в каком режиме. Для публикации кода нужен `.gitignore`.
- Если изменений нет, коммит не создаётся.
- GitHub Pages обновляет сайт за 1–2 минуты.

Обновление админки на другом компьютере:
1. Скопируйте туда `server.py`, `admin.html`, `js/admin-edit.js` и `.gitignore`. Для публикации
   кода сайта нужна вся папка проекта, кроме `secrets.json`, `works/` и `config.json`: это
   содержимое, его хранит компьютер с админкой.
2. Перезапустите `server.bat`.
3. Если при сохранении появляется «Forbidden», один раз нажмите Ctrl+F5: браузер держал старую
   админку.

Сервер слушает только свой компьютер (127.0.0.1). С телефона по Wi-Fi админка и предпросмотр не
открываются.

## Дизайн-система

Подробно — в `docs/redesign/DIRECTION.md`. Токены — в начале `css/site.css`.

| Роль | Значение |
|------|----------|
| Фон, «бархат» | `#120b13` |
| Сцена витрины | `#1a111c` |
| Текст, «платина» | `#f2edf4`, второстепенный `#c3b8c6`, подписи `#9d90a1` |
| Акцент, «шампань» | `#d9c595`: только действия, фокус и активный фильтр |
| Линии | белый 12% и 24% |
| Витрина | Футляр со светом сверху: верхняя грань белым 24%, боковые 12%, лёгкая фактура бархата |
| Фото в витрине | Снимок, близкий к 4:5 (обычный 3:4 с телефона), заполняет витрину; любой другой показывается целиком, края мягко растворяются в цвете фона самого снимка |
| Сетка работ | Каждая работа — маленькая витрина с бархатным паспарту 14 px вокруг фото |
| Бисер | Объёмные стеклянные бусины (блик, тонкий ободок, тень на ткани), кристалл в 8 граней; искры только на кристалле. Рядом с «Написать мастеру» — крупный план кристалла в обшивке |
| Текст и интерфейс | Jost 300–500 |
| Заголовки | Noto Serif Display Condensed 300 («TINOLI Display») |
| Радиус | 2 px |

Тёмная тема единственная: это решение концепции. Все шрифты лежат на своём домене и содержат
полную кириллицу. Анимации выключаются системной настройкой «уменьшить движение».

## Безопасность

| Мера | Как сделано |
|------|-------------|
| Доступ | Сервер слушает только 127.0.0.1; запросы с чужим `Host` отклоняются (защита от DNS rebinding) |
| Чужие сайты | POST-запросы требуют заголовок `X-TINOLI: admin`, свой `Origin` и `Host`, `Sec-Fetch-Site` не cross-site: страница другого сайта не может опубликовать, удалить работу или сменить токен. Админку нельзя встроить во фрейм |
| Блокировка файлов | `.py`, `.bat`, копии `secrets`, скрытые папки (`.git`, `.claude`) не отдаются ни на GET, ни на HEAD, в том числе при другом регистре, `%2E`, точке в конце, `::$DATA` и коротких именах 8.3; имена устройств Windows (`NUL`, `CON`) — 404; списков папок нет |
| Токен GitHub | Только в `secrets.json`, формат проверяется, в журнале и ответах заменяется на `***` |
| Публикация | Список «никогда не публиковать» поверх `.gitignore`; файл с токеном останавливает публикацию; массовое удаление — только после подтверждения |
| Запросы | Тело ограничено (JSON 2 МБ, фото 20 МБ), зависшее соединение закрывается через 15 с |
| Данные | `works.json` и `config.json` пишутся атомарно, предыдущая версия остаётся в `.bak` |
| Тексты из JSON | На сайте выводятся как текст, ссылки контактов проверяются |
| Персональные данные | Форм и cookies нет; Cloudflare Web Analytics без cookies и только на tinoli.ru |

## Если что-то не так

- **Сервер не запускается.** Проверьте `python --version` (нужен 3.8+). Запускайте `server.bat` из
  папки проекта.
- **Публикация пишет «GitHub токен не указан».** Вкладка «Публикация» → вставить токен → «Сохранить».
- **На сайте старый дизайн после публикации с другого компьютера.** Там лежат устаревшие файлы.
  Скопируйте свежую папку проекта или публикуйте без галочки «код сайта».
- **Сайт не обновился.** GitHub Pages обновляется за 1–2 минуты, страницы кешируются до 10 минут.
